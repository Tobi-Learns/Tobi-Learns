### 🛠️ What I've Built

**[Cadence](https://gocadence.xyz)** — AI-powered marketing content calendar. Currently in closed beta.

A full-stack SaaS I designed and built solo. It helps marketers and small businesses plan, generate, and approve social media content across platforms — all in one place. Claude AI drafts a full week of posts (with live web search for relevance), an Image Director layer generates matching visuals, and users review everything through an approval workflow before it goes out.

- **Stack:** React 18 · Node.js/Express · PostgreSQL · Prisma
- **AI:** Anthropic Claude · OpenAI image generation · Sharp compositing
- **Infra:** Cloudflare Pages · Railway · Supabase · Cloudflare R2
